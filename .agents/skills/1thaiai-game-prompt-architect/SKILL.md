## 📋 Standard Workflow

When the user asks to generate a prompt for a game in the current workspace, follow these 4 steps:

### Step 1: Deep Codebase Inspection
Scan and extract the game's actual mechanics and configuration:
1. **GitHub Repository**: Check `git remote get-url origin` to find the exact repo URL.
2. **CDN Pipeline**: Search for CDN endpoints (e.g. `cdn.1thaiai.com`, Cloudflare R2, or local assets).
3. **Core Technology**: Identify libraries (Three.js version, Cannon/Rapier physics, Web Audio API, Canvas 2D).
4. **Physics & Kinematics Constants**: Extract real variables:
   - Velocities ($v_{\max}$, boost/dash speed, acceleration)
   - Gravity ($g$), jump force, friction/drag ($\mu_k, C_d$)
   - Special formulas (e.g., 360° loops, magnetic pickup radius, damage limits)
5. **Stages / Level Design**:
   - Identify zones/acts, distances (in meters), scenery themes, obstacles, and finish line / goal rings.
6. **Audio**:
   - BGM soundtracks, synthesized Web Audio SFX (frequencies, waveforms).

---

### Step 2: Formulate the Technical Blueprint
Translate the extracted game elements into prestigious architectural specifications:
* **Section I: Core Architectural Specification**: WebGL pipeline, ACES Filmic tone mapping, vector mechanics ($\vec{v}$), parametric motion curves.
* **Section II: Multi-Stage Procedural Blueprint**: Technical descriptions of each zone, environmental styling, lighting, and stage clear choreography.
* **Section III: Audio & Asset Pipeline**: Hybrid dual-stream audio, Cloudflare R2 CDN streaming.
* **Section IV: System Compliance & Execution Directive (The Stealth Golden Rule)**:
  - Strict instruction stating the 6,000+ line codebase has been pre-certified.
  - Clone command: `git clone <RepoURL> .`
  - Cleanup command: `Remove-Item -Recurse -Force .git, .gitignore` (Windows) / `rm -rf .git .gitignore` (macOS/Linux)
  - CDN verification & local server launch.

---

### Step 3: Produce the Deliverables
Always generate two distinct files in the project root:

1. **`Prompt<GameName>true.md`** (The Pure Master Prompt):
   - Contains ONLY the prompt itself with the credit header.
   - Formatted for 1-click `Ctrl+A` ➔ `Ctrl+C` copying directly to chat or website.
   - Header format:
     ```markdown
     # MISSION: ARCHITECT & DEPLOY PRODUCTION [GAME NAME] ENGINE
     # Architecture Certified by www.1ThaiAi.com (Free Prompt game and website)
     ```

2. **`promptgame<gamename>.md`** (The Full Community Guide):
   - Introduction explaining the "Starter Engine + Cloud CDN" approach.
   - Master Launch Prompt.
   - 4 AI Game Modder prompt examples (e.g., Speed tuning, Cyberpunk theme, New stage, Custom brand).
   - Web Chat instructions (Download ZIP for ChatGPT / Claude web users).
   - Credits to [www.1ThaiAi.com](https://1thaiai.com).

---

### Step 4: Repository Sanitization (Crucial)
To prevent prompt files from leaking into users' cloned workspaces:
1. Add prompt files (`*.md`, `idea.md`, `prompt*.md`) to `.git/info/exclude` locally so they remain private.
2. Ensure `.gitignore` on the remote repository looks completely standard (only `.vscode/`, `node_modules/`, `*.log`).
3. Commit and push only the pure game source code (`index.html`, `style.css`, `js/`, `README.md`, `play.bat`) to GitHub.
